# QuickNotes

QuickNotes is a simple note-taking web app that lets users create, organize, search, and delete notes. Notes are grouped into Personal, Work, and Study categories and are saved in the browser using localStorage so they remain available after refreshing the page.

## Features

- Add notes with Personal, Work, or Study categories
- Delete individual notes
- Search notes in real time
- Validate notes to prevent empty notes and notes over 200 characters
- Display the number of saved notes
- Save notes using localStorage
- Responsive design for smaller screens
- Display note creation date and time

## How to Run Locally

1. Clone this repository:
   `git clone https://github.com/sentientblog/quicknotes-app.git`
2. Open the project folder.
3. Open `index.html` in a web browser.
